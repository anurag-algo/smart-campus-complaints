# ResolveHub Frontend

A React + Vite complaint-management frontend demo.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Included
- Dashboard, complaint submission, complaint list/detail modal, profile, login/register screens
- Responsive sidebar/navigation
- Demo complaint submissions saved in browser localStorage

## Note
This is frontend-only. Authentication, file uploads, and complaint data are not connected to a backend yet.
